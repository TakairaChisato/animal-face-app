# 動物の顔にスタンプを合成するWebアプリ

ペットの写真をアップロードすると、機械学習モデルが顔と目・鼻・口の位置を検出し、顔の向きや傾きに合わせてスタンプ（帽子、メガネ、耳、リボンなど）を自動で配置するWebアプリです。

大学の授業で、5名のチームで開発しました（2025年9月〜12月）。

---

## 主な機能

- 画像をアップロードすると、顔の位置と顔のパーツ（左右の目、鼻、口）を自動で検出
- スタンプを選ぶと、顔の大きさ・位置・傾きに合わせて自動で配置
- 横顔を判定し、横顔用の画像（片目用のメガネなど）や横幅を縮めたスタンプに切り替え
- 加工した画像のダウンロード

## 使用技術

| 分類 | 技術 |
| --- | --- |
| フロントエンド | HTML / CSS / JavaScript（Canvas API） |
| バックエンド | Python / FastAPI |
| 機械学習 | PyTorch / Faster R-CNN（顔検出）/ ResNet18（顔パーツ検出） |
| 実行環境 | Docker |

## 仕組み

1. ブラウザから画像を送信すると、バックエンドで Faster R-CNN が顔の範囲を、ResNet18 が目・鼻・口の座標を検出します
2. 検出結果はアップロードごとに発行するIDに紐づけて一時保存し、10分間操作がなければ自動で削除します
3. スタンプが選ばれると、バックエンドが座標から配置位置・大きさ・回転角度を計算して返します
4. フロントエンドが受け取った値をもとに、Canvas 上でスタンプを回転させて描画します

## 私（高井良）の担当

チームは画像認識班（Python）と Webアプリ班（JavaScript / HTML / CSS / FastAPI）に分かれており、私は Webアプリ班として、主にバックエンドの API とスタンプの角度計算を担当しました。コード内では「担当:C」と記載している箇所です。

### 1. 画像アップロードと顔パーツ検出の API（`backend.py` の `/upload_and_detect`）
- アップロード画像ごとに一意のIDを発行し、一時フォルダに保存
- 機械学習モデルを呼び出し、検出した座標を JSON として保存
- 検出結果を描画した確認用画像をフロントエンドに返却

### 2. 横顔判定と横顔用スタンプへの切り替え
- 両目の距離が顔の幅の25%未満であれば横顔と判定するロジックを実装
- 横顔のときは、鼻の位置から左右どちら向きかを判断し、メガネや目のスタンプを片側用の画像に切り替え
- 耳・リボン・口のスタンプは、横顔に合わせて横幅を縮めて自然に見えるよう調整

### 3. スタンプの回転角度の計算と描画（`backend.py` / `EffectSelect.js`）
- 両目を結ぶ線の傾きから顔の角度を算出
- スタンプごとに回転の中心を設定（帽子・耳は下辺、リボンは上辺、その他は中心）し、首をかしげた写真でも違和感なく重なるよう調整
- フロントエンド側で Canvas の座標変換（`translate` / `rotate`）を用い、指定された中心で回転させて描画

## 実行方法

> 学習済みモデルのファイルはサイズが大きいため、このリポジトリには含めていません。そのため、このリポジトリ単体ではアプリを起動できません。

前提として Docker Desktop が必要です。

1. 学習済みモデル（`fasterrcnn4_resnet18_W2_epoch_20.pth` と `model_map4.pth`）を `pet_app/backend/` に配置します
2. `pet_app` フォルダに移動し、次のコマンドを実行します

```bash
docker build -t pet_app .
docker run -p 8000:8000 pet_app
```

3. ブラウザで http://127.0.0.1:8000/static/pet.html を開きます

初回のビルドには時間がかかる場合があります。

## フォルダ構成

```
.
├── README.md                  # このファイル
└── pet_app/
    ├── Dockerfile             # 実行環境の設定
    ├── requirements.txt       # 必要なPythonライブラリ
    └── backend/
        ├── backend.py         # API（画像受付、スタンプの配置計算）
        ├── detect.py          # 学習済みモデルの読み込みと推論
        ├── resnet_map4.py     # 顔パーツ検出モデルの定義
        ├── plot_results.py    # 検出結果の可視化
        └── www/               # フロントエンド
            ├── pet.html       # 画面
            ├── *.js           # 画像読み込み、スタンプ描画などの処理
            ├── icons/         # スタンプ選択ボタンの画像
            └── effect/        # 写真に重ねるスタンプ画像
```

※ 学習済みモデル（`fasterrcnn4_resnet18_W2_epoch_20.pth`、`model_map4.pth`）は、実行時に `pet_app/backend/` に配置します。
